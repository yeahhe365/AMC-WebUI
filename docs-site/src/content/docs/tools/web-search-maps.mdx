# 联网检索与地图增强

AMC WebUI 深度集成了 Google 原生 Grounding（事实溯源检索）能力，赋予模型获取最新互联网动态与地理空间数据的能力。

---

## 1. Google 实时网络搜索 (Google Search Grounding)

- **触发方式**：在输入框下方工具栏点击 **联网搜索图标**，或输入 `/online` 命令。
- **运行机制**：模型在思考回答时，若判断需要最新实时信息，会自动构造针对性搜索词查询 Google 搜索索引。
- **引用与溯源**：返回的回复末尾会包含带编号的真实网页参考链接、网页标题与提取摘要，保证事实准确性并支持溯源查证。

---

## 2. 深度多步规划检索 (Deep Search)

相比单次普通搜索，**Deep Search** 专为复杂行业调研、多维信息对比和前沿技术排查而设计：
- **触发方式**：在工具栏选择 **深度搜索 (Deep Search)**，或输入 `/deep` 命令。
- **工作机制**：
  1. **任务规划**：模型先将复杂问题拆解为多个子查询。
  2. **多轮检索**：并发或循序调用多组 Google 搜索，并自动评估抓取结果的相关性与权威度。
  3. **综合研判**：交叉比对多方证据，输出结构化的高密度深度调研报告。

---

## 3. Google Maps 地理空间增强 (Google Maps Grounding)

- **适用模型**：`gemini-3.5-flash`、`gemini-3.8-flash` 等 Gemini 3 系列核心模型。
- **触发方式**：点击工具栏的 **地图图标** 或输入 `/maps`。
- **交互能力**：
  - 点击后可呼出 **位置拾取与坐标配置弹窗 (Google Maps Location Modal)**，支持设定当前检索的基准经纬度与城市。
  - 模型在推荐餐厅、规划旅游路线、计算路线距离时，会结合 Google Maps 真实地理空间数据库，返回精确的商户名称、地址与坐标指引。
