## 核心环境变量清单

| 变量名                            | 用途                                                       | 适用端                             | 默认值                                      |
| :-------------------------------- | :--------------------------------------------------------- | :--------------------------------- | :------------------------------------------ |
| `WEB_PORT`                        | Docker 前端容器宿主机映射端口                              | 宿主机                             | `8080`                                      |
| `PORT`                            | Node API 后端监听端口                                      | 服务端                             | `3001`                                      |
| `GEMINI_API_KEY`                  | 可选的服务端统一托管 Gemini Key                            | **仅服务端**                       | 空                                          |
| `LIVE_GEMINI_API_KEY`             | 专门用于 Live WebSocket 代理的服务端 Key                   | **仅服务端**                       | 空                                          |
| `GEMINI_API_BASE`                 | 上游 Gemini API 基地址（可指向自建反代）                   | 服务端                             | `https://generativelanguage.googleapis.com` |
| `SERVER_KEY_PRIORITY`             | `true`=服务端优先；`false`=浏览器 BYOK 优先                | 服务端                             | `false`                                     |
| `ACCESS_PASSWORD`                 | 访问口令，保护 Node API 不被匿名调用                       | **仅服务端**                       | 空                                          |
| `SERVER_ACCESS_TOKEN`             | `ACCESS_PASSWORD` 的兼容别名                               | **仅服务端**                       | 空                                          |
| `ALLOWED_ORIGINS`                 | 跨域允许的 Origin 白名单（逗号分隔）                       | 服务端                             | 空                                          |
| `ENABLE_LIVE_WS_PROXY`            | 是否启用 `/api/live` 的 WebSocket 全代理                   | 服务端                             | `true`                                      |
| `LIVE_WS_IDLE_TIMEOUT_MS`         | Live WebSocket 空闲回收超时（毫秒）                        | 服务端                             | `300000`                                    |
| `ENABLE_MCP_STDIO`                | 允许执行本地 stdio 形式的 MCP 进程                         | 服务端                             | `false`                                     |
| `ENABLE_MCP_PRIVATE_HTTP`         | 允许 MCP 访问内网/本机 HTTP 服务                           | 服务端                             | `false`                                     |
| `ENABLE_THIRD_PARTY_PRIVATE_HTTP` | 允许第三方路由访问内网/本机端点（如本地 Ollama）           | 服务端                             | `false`                                     |
| `THIRD_PARTY_ROUTES`              | 第三方服务商安全路由表 JSON                                | **仅服务端**                       | 空                                          |
| `NPM_REGISTRY`                    | 构建镜像时使用的 npm 源                                    | 构建参数                           | `https://registry.npmjs.org`                |
| `RUNTIME_SERVER_MANAGED_API`      | 前端是否使用服务端统一下发的 Key                           | 公开前端                           | `true`（Docker）                            |
| `RUNTIME_SERVER_ACCESS_PASSWORD`  | 访问受保护 Node API 的口令；**不写入 `runtime-config.js`** | 仅服务端（前端只收到一个布尔标志） | 空                                          |
| `RUNTIME_USE_API_PROXY`           | 是否让前端走服务端代理                                     | 公开前端                           | `true`（Docker）                            |
| `RUNTIME_USE_CUSTOM_API_CONFIG`   | 是否允许浏览器端自定义 API 配置覆盖                        | 公开前端                           | `true`（Docker）                            |
| `RUNTIME_API_PROXY_URL`           | 前端 Gemini 默认代理地址                                   | 公开前端                           | `/api/gemini`                               |
| `RUNTIME_LIVE_API_BASE_URL`       | 前端 Live API 连接地址（留空直连官方）                     | 公开前端                           | `/api/live`                                 |
| `RUNTIME_THIRD_PARTY_PROXY_URL`   | 前端第三方兼容代理地址（留空直连）                         | 公开前端                           | `/api/openai`                               |
| `RUNTIME_PYODIDE_BASE_URL`        | Pyodide WASM 运行时资源地址（留空使用同源 `/pyodide/`）    | 公开前端                           | 空                                          |

服务端选中的普通 Gemini Key 始终使用 `GEMINI_API_BASE`；浏览器自定义地址仅对浏览器 BYOK Key 生效。`GEMINI_API_BASE` 是管理员受信任配置，可以指向本地反代。受限制的代理在实际连接时检查 DNS，MCP 不跟随跨源或 HTTPS 降级重定向。保留 `198.18.0.0/15` 的 Fake-IP 兼容，用于 Clash/Surge/Mihomo TUN。

流式任务默认最多同时运行 32 个任务，保留 256 个任务、全局 64 MiB 历史，单个事件和单任务历史各为 8 MiB。空闲 120 秒、运行 1 小时终止；已完成历史保留 10 分钟。Compose 可用 `AMC_STREAM_JOB_*` 环境变量调整。历史过期或被淘汰时续传返回 `409`，前端应保留已有内容并重新发起请求；内存历史不跨进程重启保存。

默认构建按安装的 Pyodide 清单下载科学计算包、校验 SHA-256 并缓存。使用外部版本化资源时，可执行 `PYODIDE_ASSETS_EXTERNAL=true pnpm run build` 省略同源资源，同时设置匹配版本的 `RUNTIME_PYODIDE_BASE_URL`。

## ⚠️ 安全边界声明

当前 `web + api` 方案定位为**可信自托管环境 (Trusted Self-Hosted)**：

- 默认的 BYOK 模式使用浏览器填写的 Key 发送请求，该设计本身**不能作为公开互联网下无鉴权的商用 API 网关**。
- 若需对公网未知多用户开放，请务必在前置代理（如 Nginx、Traefik）中增加强身份认证与访问频率限制。
