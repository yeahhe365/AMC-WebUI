# 静态托管 + 独立 API 部署

如果你希望将前端部署在 Cloudflare Pages、Vercel 或 AWS S3 享受全球边缘 CDN 带来的极致加载速度，同时把需要服务端密钥的 Node API 部署在独立云服务器上，可采用**动静分离架构**。

---

## 1. 前端构建与 Pages 部署
1. 在项目根目录构建前端纯静态包：
   ```bash
   pnpm run build
   ```
2. 将输出目录 `dist/` 部署至 Cloudflare Pages 或 Vercel。
3. 在部署设置中将输出目录指向 `dist`，构建命令为 `pnpm run build`。

---

## 2. 后端独立 API 启动
在独立服务器（如 Ubuntu / Debian 虚拟机）上：
```bash
# 编译并启动 Node API 服务
pnpm run build:api
pnpm run start:api
```

### 跨域白名单配置 (`ALLOWED_ORIGINS`)
由于前端与后端处于不同域名，必须在后端环境配置允许跨域访问的前端域名：
```bash
PORT=3001
ALLOWED_ORIGINS=https://your-amc-app.pages.dev,https://chat.yourdomain.com
GEMINI_API_KEY=AIzaSyYourServerManagedKey
```

---

## 3. 前端与后端对接
打开部署好的前端页面，进入 **设置 -> 服务商与 API**：
- 开启「自定义 API 配置 / 代理」。
- 填写后端的公开 API 地址，例如：`https://api.yourdomain.com/api/gemini`。
- 此时普通的 Gemini 请求即走你的后端服务器代理，兼顾了前端的高速缓存与后端的安全代理。
