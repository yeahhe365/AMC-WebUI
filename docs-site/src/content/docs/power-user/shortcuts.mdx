# 快捷键与快速切换 (Shortcuts & Gestures)

AMC WebUI 为键盘流极客设计了深度的按键驱动工作流，让高频操作行云流水。

---

## 1. Tab 键轮巡常用模型 (Tab Cycle Models)

- **使用场景**：在日常工作中经常需要在思考模型（`gemini-3.8-flash`）、高智力大模型（`gemini-3.1-pro-preview`）与轻量模型（`gemini-3.5-flash-lite`）之间来回切换比对效果。
- **操作方式**：在输入框内按下 `Tab` 键，可在收藏的模型列表中按顺序直接轮巡切换当前活动模型。
- **自定义配置**：在 **设置 -> 快捷键 -> Tab 轮巡模型** 中，可自由勾选或调整加入轮巡的模型序列。

---

## 2. 划词向模型提问 (Selection Ask Model)

在阅读长篇模型回复或历史对话时：
1. **划取文本**：用鼠标选中消息气泡内的任意一段文字或代码片段。
2. **浮动动作条**：文本上方会立即呼出「向模型提问」的便捷动作栏。
3. **快捷提问**：点击后，选中的文字会自动作为引用上下文注入输入框，支持一键发送「解释这段代码」、「翻译成英文」或「重写优化」，无需繁琐的复制粘贴。

---

## 3. 队列发送机制 (Queued Submissions)

当模型正在流式输出一段长文，而你突然产生了新的追问时：
- 无需等待当前生成完毕！直接在输入框输入新问题并回车。
- AMC WebUI 会将其放入 **提交任务队列 (Queued Submissions List)**。
- 当前消息生成结束后，系统会自动依次取出队列中的问题继续向模型发起多轮请求，保持思绪不被打断。

---

## 4. 全局核心快捷键汇总

| 操作 | macOS 快捷键 | Windows / Linux 快捷键 |
| :--- | :--- | :--- |
| **发送消息** | `Enter` (或 `Cmd + Enter`) | `Enter` (或 `Ctrl + Enter`) |
| **换行** | `Shift + Enter` | `Shift + Enter` |
| **新建对话** | `Cmd + Shift + O` | `Ctrl + Shift + O` |
| **全局命令面板** | `Cmd + Shift + P` | `Ctrl + Shift + P` |
| **搜索历史会话** | `Cmd + K` | `Ctrl + K` |
| **打开开发者日志** | `Cmd + Option + L` | `Ctrl + Alt + L` |
| **切换画中画 (PiP)** | `Cmd + Option + P` | `Ctrl + Alt + P` |
| **编辑上一条消息** | 输入框空白时按 `↑` | 输入框空白时按 `↑` |
| **Tab 轮巡模型** | 输入框中按 `Tab` | 输入框中按 `Tab` |
| **终止当前生成** | `Escape` | `Escape` |
