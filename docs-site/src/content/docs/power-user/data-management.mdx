# 会话与数据管理 (Data & Sessions)

在 Local-First 设计下，你的所有知识资产都完整存放在本地浏览器中。AMC WebUI 提供了完整的组织与维护工具。

---

## 1. 全文检索 (Full-Text Search)
- 侧边栏顶部提供快速搜索框（快捷键：点击放大镜或使用命令）。
- **双重检索深度**：不仅匹配会话标题，还会对所有历史会话的**所有消息正文进行即时全文倒排索引搜索**，点击检索结果可平滑定位并高亮目标消息。

---

## 2. 分组、置顶与智能归档
- **置顶重要会话**：在会话右键菜单点击「置顶」，或在输入框使用 `/pin`，该会话将永远悬停在侧边栏最顶端。
- **自定义分组文件夹**：可创建「工作调研」、「代码重构」、「生活闲聊」等文件夹，拖拽会话进行归档收纳。

---

## 3. 数据备份、导出与迁移
进入 **设置 -> 数据管理 (Data Management)**：
- **完整导出 JSON**：一键将所有会话历史、自定义模型列表、快捷键设置与偏好完整打包导出为单一 `.json` 文件。
- **单会话导出**：支持将单场对话导出为格式精美的 **Markdown (.md)**、**PNG 长截图** 或 **PDF** 文档。
- **数据恢复与导入**：更换电脑或重装系统后，导入历史 `.json` 文件即可无缝还原所有对话与设置。
- **缓存清理**：支持选择性清空本地大文件缓存，同时保留核心对话文本。
