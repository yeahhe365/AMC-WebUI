## Core Capabilities

<CardGrid stagger>
  <Card title="Deep Reasoning (Thinking)" icon="open-book">
    Visualized chain-of-thought for Gemini 3.x models, custom token budgets, and real-time thought translation. [Explore
    Thinking Mode & Translation →](/en/models/thinking/)
  </Card>
  <Card title="Real-time Audio & Video (Live API)" icon="laptop">
    Bidirectional streaming voice calls, screen sharing, camera vision input, and AudioWorklet visualization. [Learn
    about Live API Voice & Vision →](/en/models/live-api/)
  </Card>
  <Card title="Live Artifacts" icon="puzzle">
    Automatic sandbox rendering of interactive HTML/SVG with Apache ECharts, Mermaid flowcharts, and Graphviz. [Explore
    Chart Sandbox & Visualizations →](/en/tools/live-artifacts/)
  </Card>
  <Card title="Local Python Sandbox (Pyodide)" icon="setting">
    Browser-side WASM environment with numpy/pandas preloaded, dynamic package installation, and plot capture. [Discover
    WASM Python with Pyodide →](/en/tools/code-and-sandbox/)
  </Card>
  <Card title="Model Context Protocol (MCP)" icon="add-document">
    Full MCP client supporting local stdio and remote SSE/Stream servers with human-in-the-loop tool approvals. [Connect
    Stdio & SSE MCP Servers →](/en/tools/mcp/)
  </Card>
  <Card title="Local-First Architecture" icon="bars">
    IndexedDB persistence with Web Locks API concurrency control; Gemini and OpenAI settings strictly isolated. [Read
    Local Storage & Security Specs →](/en/deployment/architecture/)
  </Card>
</CardGrid>
