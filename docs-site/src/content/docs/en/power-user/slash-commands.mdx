# Slash Commands

Type `/` in the chat input to invoke the command menu. Navigate using arrow keys and press Enter to execute commands without touching your mouse.

## Power User Tips

### 1. Fast Model Switching (`/model`)

Type `/model` to expand the inline model search panel. Filter through configured endpoints and press Enter to switch models instantly.

### 2. Instant Thinking Toggle (`/fast`)

When you need a quick answer in a complex conversation, submit `/fast` to drop thinking depth to `Minimal` (only Flash / Robotics models that accept Minimal, such as `gemini-3.5-flash-lite`) or `Low` (all other models, including `gemini-3.8-flash`, which rejects Minimal). Run `/fast` again to leave the lightweight tier.

### 3. Immediate Tool Toggles

- `/online`: Toggle Google search grounding.
- `/deep`: Enable deep multi-step planning search (Deep Search).
- `/maps`: Open Google Maps location search.
- `/code`: Toggle Python execution runtime.
- `/url`: Fetch a URL's content into the conversation context.
- `/file`: Launch the attachment file picker immediately.
