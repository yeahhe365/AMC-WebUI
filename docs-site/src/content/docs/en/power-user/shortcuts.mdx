# Shortcuts & Ergonomics

AMC WebUI is engineered with a keyboard-first philosophy for rapid, friction-free operation.

---

## 1. Tab Key Model Cycling

- **Workflow**: Instantly toggle between your go-to models (e.g., `gemini-3.8-flash`, `gemini-3.1-pro-preview`, `gemini-3.5-flash-lite`) to compare answers.
- **Action**: Press `Tab` inside the chat input to cycle through your favorited model rotation.
- **Customization**: Configure your cycle sequence in **Settings -> Shortcuts -> Tab Cycle Models**.

---

## 2. Selection Ask Model

When inspecting long responses or code blocks:
1. **Highlight Text**: Select any text or code snippet within a message bubble.
2. **Action Popover**: A contextual popover automatically docks near your selection.
3. **One-click Inquiry**: Click prompt presets (e.g., "Explain this", "Refactor", "Translate") to inject the quoted context directly into the conversation without copy-pasting.

---

## 3. Queued Submissions

When inspiration strikes while the model is still generating:
- Type your next instruction and press Enter immediately.
- AMC WebUI registers the prompt in the **Queued Submission List**.
- Once the current turn finishes, queued prompts dispatch automatically in sequence.

---

## 4. Key Global Shortcuts

| Action | macOS | Windows / Linux |
| :--- | :--- | :--- |
| **Send Message** | `Enter` (or `Cmd + Enter`) | `Enter` (or `Ctrl + Enter`) |
| **New Line** | `Shift + Enter` | `Shift + Enter` |
| **New Chat** | `Cmd + Shift + O` | `Ctrl + Shift + O` |
| **Command Palette** | `Cmd + Shift + P` | `Ctrl + Shift + P` |
| **Search Chats** | `Cmd + K` | `Ctrl + K` |
| **Developer Logs** | `Cmd + Option + L` | `Ctrl + Alt + L` |
| **Toggle PiP** | `Cmd + Option + P` | `Ctrl + Alt + P` |
| **Edit Last Message** | `↑` (when input is empty) | `↑` (when input is empty) |
| **Cycle Models** | `Tab` in input box | `Tab` in input box |
| **Stop Generating** | `Escape` | `Escape` |
